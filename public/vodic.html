7. Ista logika, razpisana za branje

Spodnji izseki so učna razširitev trenutne logike. Uporabljajo več vmesnih spremenljivk in vrstic. Izvorne datoteke ostanejo nespremenjene.

A. Kaj naredi updateDiagram

function updateDiagram(update: Partial<typeof diagram>) {
  const nextDiagrams = project.diagrams.map(current => {
    if (current.id !== mode) {
      return current;                 // drugih diagramov ne spreminjamo
    }

    return {
      ...current,                    // ohrani obstoječa polja
      ...update,                     // prepiši samo podana polja
    };
  });

  const nextProject = {
    ...project,
    diagrams: nextDiagrams,
  };

  change(nextProject);               // zgodovina + naslednje stanje
}

Partial pomeni, da ni treba podati celotnega diagrama. Če podamo samo { name: "Nov naslov" }, njegovi nodes in edges ostanejo isti.

B. Kako editNode ohrani ostale lastnosti

function editNode(data: Partial<ElementData>) {
  if (!selectedNode) return;

  const nextNodes = diagram.nodes.map(current => {
    if (current.id !== selectedNode.id) return current;

    return {
      ...current,
      data: {
        ...current.data,
        ...data,
      },
    };
  });

  updateDiagram({ nodes: nextNodes });
}

Če spremeniš samo ime, data vsebuje samo label. Notranji spread ohrani kind, body in druga polja. Zunanji spread ohrani id in position. Predmetov ne urejamo s current.data.label = ....

export function checkDiagram(d: Diagram): string[] {
  const issues: string[] = [];
  if (!d.nodes.length) return ['Diagram je prazen. Dodaj prvi element.'];
  for (const n of d.nodes) {
    const incoming = d.edges.filter(e => e.target === n.id);
    const outgoing = d.edges.filter(e => e.source === n.id);
    const label = n.data.label || kinds[n.data.kind];
    if (!n.data.label.trim()) issues.push(`${label}: manjka ime.`);
    if (d.nodes.length > 1 && !incoming.length && !outgoing.length && n.data.kind !== 'note') issues.push(`${label}: element ni povezan.`);
    if (d.id === 'activity') {
      if (n.data.kind === 'decision' && outgoing.length !== 2) issues.push(`${label}: odločitev potrebuje dve izhodni veji.`);
      if (n.data.kind === 'fork' && outgoing.length < 2) issues.push(`${label}: razcep potrebuje vsaj dve veji.`);
      if (n.data.kind === 'join' && incoming.length < 2) issues.push(`${label}: združitev potrebuje vsaj dva vhoda.`);
      if (n.data.kind === 'start' && (incoming.length || outgoing.length !== 1)) issues.push(`${label}: začetek potrebuje en izhod in nobenega vhoda.`);
      if (n.data.kind === 'end' && outgoing.length) issues.push(`${label}: konec ne sme imeti izhoda.`);
      if (!['end', 'decision', 'fork', 'start'].includes(n.data.kind) && !outgoing.length) issues.push(`${label}: manjka naslednji korak.`);
    }
  }
  if (d.id === 'activity') {
    const starts = d.nodes.filter(n => n.data.kind === 'start');
    if (starts.length !== 1) issues.push('Aktivnosti potrebujejo natanko en začetek.');
    if (!d.nodes.some(n => n.data.kind === 'end')) issues.push('Aktivnosti potrebujejo vsaj en konec.');
    if (starts.length === 1) {
      const reached = new Set([starts[0].id]);
      for (let i = 0; i < d.nodes.length; i++) for (const e of d.edges) if (reached.has(e.source)) reached.add(e.target);
      for (const n of d.nodes) if (!reached.has(n.id)) issues.push(`${n.data.label}: ni dosegljiv iz začetka.`);
    }
  }
  return [...new Set(issues)];
}

export function toPlantUml(d: Diagram): string {
  const aliases = new Map(d.nodes.map((n, i) => [n.id, `n${i}`]));
  const lines = ['@startuml', `title ${literal(d.name)}`, 'skinparam shadowing false'];
  if (d.id === 'activity') {
    const issues = checkDiagram(d);
    if (issues.length) throw new Error(issues.join('\n'));
    const declared = new Set<string>();
    const emitted = new Set<string>();
    const queue = [d.nodes.find(n => n.data.kind === 'start')!];
    const byId = new Map(d.nodes.map(n => [n.id, n]));
    const ref = (n: DiagramNode): string => {
      const alias = aliases.get(n.id)!;
      if (n.data.kind === 'start' || n.data.kind === 'end') return '(*)';
      if (n.data.kind === 'fork' || n.data.kind === 'join') return `===${alias}===`;
      if (declared.has(n.id)) return alias;
      declared.add(n.id);
      return `${quoted(n.data.label)} as ${alias}`;
    };
    function emit(source: string, e: Diagram['edges'][number]) {
      if (emitted.has(e.id)) return;
      emitted.add(e.id);
      const target = byId.get(e.target)!;
      const label = e.data?.label ? `[${literal(e.data.label).replace(/[\[\]]/g, '')}]` : '';
      if (target.data.kind === 'decision' && !declared.has(target.id)) {
        declared.add(target.id);
        lines.push(`${source} -->${label} if ${quoted(target.data.label)} as ${aliases.get(target.id)} then`);
        const branches = d.edges.filter(link => link.source === target.id);
        emit('', branches[0]);
        lines.push('else');
        emit('', branches[1]);
        lines.push('endif');
      } else {
        lines.push(`${source} -->${label} ${ref(target)}`);
        queue.push(target);
      }
    }
    const visited = new Set<string>();
    while (queue.length) {
      const n = queue.shift()!;
      if (visited.has(n.id)) continue;
      visited.add(n.id);
      for (const e of d.edges.filter(link => link.source === n.id)) emit(ref(n), e);
    }
    // shortcut: legacy activities carry descriptions as source comments; use attached notes when activity note placement is added.
    for (const n of d.nodes) if (n.data.description) for (const line of n.data.description.split('\n')) lines.push(`' ${literal(n.data.label)}: ${member(line)}`);
  } else {
    lines.push('allowmixing', 'skinparam classAttributeIconSize 0', 'skinparam linetype ortho', 'hide empty members');
    const groups = [...new Set(d.nodes.map(n => n.data.group))];
    for (const group of groups) {
      if (group) lines.push(`package ${quoted(group)} {`);
      for (const n of d.nodes.filter(n => n.data.group === group)) {
        const { kind, label, body, stereotype } = n.data;
        const alias = aliases.get(n.id)!;
        if (kind === 'note') {
          lines.push(`note ${quoted([label, body].filter(Boolean).join('\n'))} as ${alias}`);
          continue;
        }
        const tag = stereotype ? ` <<${literal(stereotype).replace(/[<>]/g, '')}>>` : '';
        lines.push(`${kind} ${quoted(label)} as ${alias}${tag}${body ? ' {' : ''}`);
        if (body) lines.push(...body.split('\n').map(s => `  ${member(s)}`), '}');
      }
      if (group) lines.push('}');
    }
    for (const e of d.edges) {
      const data = e.data!;
      lines.push(`${aliases.get(e.source)}${data.sourceCardinality ? ` ${quoted(data.sourceCardinality)}` : ''} ${data.relation}${data.targetCardinality ? ` ${quoted(data.targetCardinality)}` : ''} ${aliases.get(e.target)}${data.label ? ` : ${literal(data.label)}` : ''}`);
    }
    for (const n of d.nodes) if (n.data.description) lines.push(`note right of ${aliases.get(n.id)} : ${literal(n.data.description)}`);
  }
  return [...lines, '@enduml'].join('\n');
}

10. Kako iz grafa nastane PlantUML

Arhitektura in ER: deklaracije, potem povezave

  1. Map priredi kratko ime vsakemu id: Customer postane n0, Order n1.
  2. Vozlišča se združijo po data.group v pakete.
  3. kind določi ključno besedo, npr. class, interface ali entity.
  4. body se razdeli na vrstice atributov in metod.
  5. Iz edges nastanejo relacije z oznakami in kardinalnostmi.
  6. description se doda kot PlantUML opomba.
@startuml
entity "Customer" as n0 {
  * customerId: long <<PK>>
}
entity "Order" as n1 {
  * orderId: long <<PK>>
}
n0 "1" -- "0..*" n1 : naročila
@enduml
